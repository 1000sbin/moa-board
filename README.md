# 🧊 모아보드 (Moaboard)

집에서 작업하는 사람을 위한 **윈도우 데스크톱 작업 대시보드**예요.
작업 시간이 자동으로 기록되고, 할 일·일정·습관·목표를 한 화면에서 관리할 수 있어요.

> 💗 커미션 일러스트, 코딩처럼 **오래 앉아서 하는 작업**의 시간을 재고,
> 마감과 할 일을 놓치지 않으려고 만들었어요.

---

## ✨ 뭘 할 수 있나요

- **⏱ 워크 트래커** — 지금 켜놓은 프로그램을 알아서 감지해서 작업 시간을 자동으로 재요. (예: 클립스튜디오를 켜면 "그림 작업" 시간이 쌓임) 자리를 비우면 알아서 멈춰요.
- **✅ 할 일** — 오늘 할 일을 적고 체크. 완료율이 한눈에.
- **📅 일정 · D-day** — 일정을 달력에 표시하고, 마감은 "D-3"처럼 남은 날짜로 보여줘요.
- **🔥 습관** — 물 마시기·운동처럼 매일 하고 싶은 걸 요일별로 체크.
- **📝 메모** — 떠오르는 걸 태그로 분류해서 저장.
- **🎯 이번 달 목표 / 연간 목표** — 목표를 세우고 진행률을 눈으로 확인. 작업 시간 목표는 트래커가 자동으로 채워줘요.

모든 화면이 하나의 대시보드로 모여 있어서, 켜두기만 하면 오늘 뭘 했고 뭘 해야 하는지 바로 보여요.

---

## 📥 설치하기

1. 오른쪽의 [**Releases**](https://github.com/1000sbin/moa-board/releases) 로 들어가세요.
2. 최신 버전에서 아래 파일 중 하나를 받으세요:
   - **`모아보드 Setup x.x.x.exe`** — 설치형 (바탕화면 바로가기가 생겨요. 추천)
   - **`모아보드 x.x.x.exe`** — 무설치형 (다운받은 파일을 바로 실행. USB에 넣어 다녀도 돼요)
3. 받은 파일을 실행하면 끝! 

> ⚠️ 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜰 수 있어요.
> 개인이 만든 앱이라 그래요. **[추가 정보] → [실행]** 을 누르면 됩니다.

---

## 💾 내 데이터는 어디 있나요

- 모든 데이터는 **내 컴퓨터에만** 저장돼요. 인터넷으로 어디 보내지 않아요. **서버도, 로그인도 없어요.**
- 저장 위치: `%APPDATA%\moaboard\moaboard.db`
- 앱을 지워도 이 파일은 남아있어요. 완전히 지우려면 위 폴더를 삭제하세요.

---

## 🔄 업데이트

새 버전이 나오면 **앱이 알아서 받아둬요.** 다음에 껐다 켜면 최신 버전으로 실행돼요.
따로 다시 받을 필요 없어요.

---

## 🖥 창을 닫아도 계속 켜져 있어요

- 창의 X를 눌러도 종료되지 않고 **작업표시줄 오른쪽 아래(트레이)로 숨어요.** 그래야 작업 시간을 계속 기록할 수 있거든요.
- 완전히 끄려면 트레이에서 모아보드 아이콘을 **우클릭 → 종료**.
- 컴퓨터를 켜면 자동으로 실행돼요. (원치 않으면 앱 설정에서 끌 수 있어요)
